Resolve missing family links

Some animals have a mother or father ID saved as text because that parent was not in the ELN at the time. This check searches all animal records for parents that have since been added.

Scan database only finds possible matches; it does not change any animals. Review the results, uncheck any links you do not want, then choose Resolve selected links.

Only a unique Animal ID match is offered. Capital letters and spaces around an ID are ignored.

Resolving a link connects an existing parent to its offspring. The original recorded ID is kept. Already linked parents are left alone, and IDs with no matching animal stay as text.
